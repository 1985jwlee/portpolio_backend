# 코드 해설 — deviation-log DV-008 행 줄바꿈 정정

## TL;DR — 이 변경을 한 문장으로
- `docs/deviation-log.md` 의 DV-008 행(30~32행)은 코드 스팬 안에 실제 개행(LF)·탭(TAB)이 들어 있어 표 한 행이 3줄로 쪼개져 있었고, 그 문자들을 이스케이프 글자(`\n`·`\t`)로 바꿔 한 줄로 되돌렸다. 내용은 그대로이고 변경은 1행 추가·3행 삭제다.

## 전체 그림
- 편차 로그는 마크다운 표라서 한 행은 물리적으로 한 줄이어야 한다. DV-008 의 "사유·해결" 칸에 있던 JS 코드 조각 `` `( LF TAB value LF );` `` 가 문자 그대로 개행·탭을 담고 있어서 행이 깨졌다.
- 이번 런은 사용자가 게이트에서 범위를 "DV-008 줄바꿈 정정만" 으로 좁혔다. S1-17 본 작업(PR 템플릿, 열 수·링크 점검 스크립트)은 하지 않았다.

## 코드 블록별 해설
### docs/deviation-log.md:30 — DV-008 행
- **목적**: 깨진 표 행을 복구한다.
- **한 줄 해설**: 바이트열 `( LF TAB value LF );` 를 `( \ n \ t value \ n );` 로 치환했다. 길이가 11 에서 14 로 늘었고, 원본 패턴은 0회·치환 결과는 1회 남았다(리뷰 재현 스크립트로 확인, 치환 결과와 작업 트리가 일치).
- **수정 포인트**: 선택지는 이스케이프 텍스트(채택, 추천안 A)와 코드 스팬을 없애고 말로 풀어쓰기였다. 채택안은 원문 의미가 가장 덜 바뀐다. 다만 이스케이프 글자는 "개행이 있었다" 는 뜻을 독자가 해석해야 한다.

## "이제 혼자 수정하려면"
- 표 셀에 코드 조각을 넣을 때는 `docs/deviation-log.md` 에서 개행·탭을 문자로 넣지 말고 `\n`·`\t` 글자로 쓴다. 인라인 코드 스팬은 표 행 하나를 넘길 수 없다.
- 행이 깨졌는지 보려면 해당 행 번호가 연속인지, 그리고 `|` 열 수가 헤더와 같은지 센다. 이 점검을 자동화하는 스크립트는 이번 런에서 만들지 않았고 S1-17 본 작업으로 남았다.
- 미반영 항목(의도된 미룸): `.github/` PR 템플릿, 열 수·링크 점검 스크립트·시험·package.json 스크립트, `tech-debt.md` 7-2·7-11 해시 칸, 7-10, DV-015, 32행에 남아 있을 수 있는 빈 코드 스팬(백슬래시 유실 의심, 이번 변경 뒤 위치가 바뀌었을 수 있어 다시 찾아야 한다).
