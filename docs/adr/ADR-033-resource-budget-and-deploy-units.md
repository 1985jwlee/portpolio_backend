# ADR-033: 자원 예산과 배포 단위 — 상시 60% 이하, CPU 예산 분리, 같은 이미지 유지
- 상태: **Proposed** (사용자 확정 대기)
- 날짜: 2026-11-04
- 근거: 무료 호스팅 제약(집 PC 16GB / Oracle 24GB 가정) / M1 실측(Bun 서버 36–90MB, Next 164MiB, Envoy 17–54MiB) / 이번 유휴 측정(postgres 56MiB, nginx 7.5MiB, prometheus 46MiB, grafana 440MiB, redis 6.8MiB, valkey 5.9MiB) / ADR-002
- 관련 문서: [phases/00 §10~11](../design/phases/00-platform-evolution.md)

## 맥락
Phase 가 올라가며 컨테이너와 레플리카가 늘고, KataGo 는 CPU·메모리를 크게 쓴다. 상한 없이 늘면 라이브 사이트가 위험해진다.

## 결정
1. **라이브 상시 메모리 합은 호스트 RAM 의 60% 이하**로 유지한다(16GB 면 9.6GiB).
2. **KataGo 분석은 메모리와 별도로 CPU 시간 예산**을 둔다: 스레드·동시성 1·방문 수 상한·낮은 우선순위, 사이트용 코어와 `cpuset`/limits 로 분리(제안).
3. 컨테이너 수 증가는 **Redis 1개(Phase 3, 단일 인스턴스)와 analysis-worker 1개(Phase 2, 별도 이미지 `pf-analysis`)** 뿐이다. 분석 동시성은 **1** 이고(늘리려면 CPU 예산을 다시 산정), 메모리 한도는 S0 스파이크 실측 후 정한다. 나머지는 같은 이미지의 엔트리포인트·레플리카로 푼다(ADR-002).
4. **Phase 4 배포 단위**: `api`, `ws-gateway(site|room)`, `worker`, `analysis-worker`, `web`. 롤링은 M1 G8 패턴(readyz 503 → bye/1001 → preStop 5초)을 재사용한다.
5. 총합 추정과 그 근거는 phases/00 §11 에 두고, **측정값과 추정값을 구분**해 Phase 시작 때마다 실측으로 갱신한다.

## 설계 상세
M1 합 약 1.12–1.54GiB(구성요소 합: phases/00 §11.1 의 하한/상한을 직접 더함, 추정), Phase 3 약 2.9–3.3GiB(KataGo 1.5GiB 가정, redis 상한 256MiB 로 계산), Phase 4 약 3.1–3.6GiB. 16GB 호스트 대비 각각 약 7–10%, 18–21%, 19–23%. KataGo 메모리는 **미확인**(모델·스레드 선택 후 측정). Grafana 유휴 440MiB 가 단일 최대 항목이므로 Phase 시작 때 유지 필요성을 점검(공개 대시보드 필수 아님이면 부하 시 기동 조정).

## 대안과 기각 이유
- **상한 없이 운영**: 사고 위험.
- **KataGo 를 외부 호스트로**: 무료·무카드 원칙과 단순성 훼손. 필요 시 재검토.
- **Grafana 제거**: 공개 지표 대시보드가 이 사이트의 핵심 볼거리(FR-061)라 유지.

## 결과
- 얻는 것: 단계마다 자원 위험이 숫자로 보이고, 분리 시 사이트 보호 규칙이 있다.
- 치르는 것: Phase 시작 때 실측 갱신 작업, CPU 분리 설정 관리.

## 위험과 완화
| 위험 | 완화 |
|---|---|
| KataGo 가 예상보다 큼 | 작은 모델/스레드 제한, 큐 적체 허용, 오프피크 실행 |
| WSL2·Oracle 메모리 상한이 다름 | 호스팅 확정 시 확인(미확인), 예산을 호스트별로 재계산 |
| 레플리카 증가로 DB 커넥션 한도 | 커넥션 풀 상한 표 작성(영역 설계에서) |

## 검증 방법
Phase 시작·종료 때 `docker stats` 스냅샷을 문서에 기록, 부하 시험 중 호스트 RAM 60% 경보(F17).

## 실서비스라면
오토스케일·전용 노드 풀·리소스 쿼터로 워크로드를 격리하고 비용 지표를 둔다.

## 재검토 조건
호스트 변경, KataGo 실측 결과, Grafana 대체/제거 결정.

## 관련 ADR
ADR-002, ADR-014, ADR-022, ADR-024, ADR-030
