# ADR-015: 타깃 서사, 모의 면책, 외부 참고 금지·비공개 범위
- 상태: Accepted
- 날짜: 2026-11-03
- 근거: 원 계획안 모순 #12, 면책, Part 3 / 인터뷰 R1-Q2, R2-Q1, R3-Q3

## 맥락
원 계획안은 타깃 포지션이 3개(Architect / Tech Lead / Full-Stack)로 서사가 분산돼 있었다. 또한 결제·정산·포인트를 다루므로 오해 소지가 있고, 이 저장소는 개발용 에이전트 시스템을 함께 들고 있어 **무엇이 공개 범위인지** 정리가 필요하다.

## 결정

### 서사
**백엔드 중심 풀스택 엔지니어**로 확정한다. 스타트업에서는 직책 타이틀보다 **"혼자 끝까지 만드는 사람"** 이 더 설득력 있다. 서사: "게임 9년 + 실시간/결제/인프라까지 혼자 설계·구현·배포". Unity 경력은 이력서 경력란과 README 의 배경 문단에서 어필한다(ADR-004).

### 대상 독자
다양한 스타트업의 채용 담당자·방문자. 사이트는 웹 전용, 한국어+영어.

### 모의 면책
모든 결제·정산·포인트는 **모의(시뮬레이션)/테스트넷**이며 실제 금전 거래가 없다. README 상단과 결제 관련 화면에 명시한다. 실제 금전·환전 가능한 재화가 없으므로 사행성·금융 규제 우려는 이 표기로 충분하다고 판단한다.

### 범위 규칙
| 규칙 | 내용 |
|---|---|
| 외부 프로젝트 비참고 | 이 저장소 밖의 다른 프로젝트·구성은 구현 과정에서 참고하지 않는다. 필요한 지식은 이 저장소의 문서·스킬에서 얻는다 |
| 에이전트 시스템 부분 추적 | 개발용 에이전트 시스템은 사이트·README 의 소개 대상이 아니다. **추적하는 것**: `.claude/` 의 진입점·설정·프로젝트 고유 데이터(`AGENT.md`, `settings.json`, `verification.json`, `check-rules.json`, `regression-replay.json`, `file-index-ignore`)와 `CLAUDE.md`. **추적하지 않는 것**: 에이전트·스킬·규약·스크립트 등 엔진 본체(`.claude/agents`, `commands`, `agent-rules`, `reference`, `rules`, `scripts`, `skills`), `.claude/kb`, `.agents/`, `.codex/`, 실측 기록. 엔진 본체는 다른 프로젝트에서 다시 흡수해 쓴다 |
| 프로젝트 목록 페이지 없음 | 사이트는 이 프로젝트 자체가 작품이다 |

## 대안과 기각 이유
- **Architect / Tech Lead 포지션**: 스타트업에서 설득력이 약하다.
- **면책 없이 진행**: 오해 가능성.

## 결과
- 얻는 것: 일관된 서사, 법적·오해 위험 감소, 공개 범위의 명확화.
- 치르는 것: 클론한 곳에는 `settings.json` 의 훅과 `AGENT.md` 의 참조가 가리키는 엔진 본체가 없다. **엔진을 다시 흡수하기 전까지 훅이 없는 스크립트를 호출하고 참조가 깨진다.** 클론 직후 엔진 흡수가 첫 작업이다.

## 위험과 완화
| 위험 | 완화 |
|---|---|
| 클론 직후 엔진 부재로 훅·참조가 깨짐 | 엔진 흡수를 클론 직후 절차로 문서화(README). 흡수 원본은 다른 프로젝트 쪽 엔진 |
| 무시 규칙에도 불구하고 비밀값이 추적됨 | 커밋 전 스테이징 목록 점검, `.codex/omniroute.env` 는 이중으로 무시 |
| 면책 누락 | 결제 화면·README 상단 체크리스트에 포함 |

## 검증 방법
공개 전 점검표: README 면책 문구, 결제 화면 표기, 비밀값 부재, 엔진 본체가 추적되지 않는지(`git ls-files` 에 `.claude/skills`·`.claude/agents`·`.codex`·`.agents` 없음), 추적 대상 파일에 다른 프로젝트 이름이 없는지.

## 실서비스라면
실제 금전이면 라이선스·정산 법규 검토가 선행돼야 한다.

## 재검토 조건
타깃을 바꿀 때, 실제 금전 요소를 도입할 때.

## 관련 ADR
ADR-004, ADR-008, ADR-011
