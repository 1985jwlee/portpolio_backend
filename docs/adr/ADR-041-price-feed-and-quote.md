# ADR-041: 시세 피드와 견적 — 소스, 교차 검증, fail-closed
- 상태: **Proposed** (사용자 확정 대기)
- 날짜: 2026-11-04
- 근거: ADR-011(스냅샷 + 견적 TTL, 소스·허용 지연·괴리 한도 미결) / 2026-11-04 시세 소스 웹 검색(요약 수준, 재확인 필요)
- 구현 순서(P0 D24): Phase 5. Phase 3 에도 **최소 `pricefeed`(고정 환율 소스 `FixedRateSource`)** 가 있어 모든 결제가 스냅샷을 갖는다(`legacy_demo` 폐기, P0 §1.4 G3·[ADR-048](ADR-048-mock-currency-and-mixed-payment.md)). Phase 5 가 실제 소스·교차 검증을 추가한다.
- 관련 문서: [design/phases/02-commerce.md](../design/phases/02-commerce.md) §8

## 맥락
ADR-011 은 방향(스냅샷, 견적 TTL, fail-closed)을 정했지만 소스, 수집 주기, 허용 지연, 괴리 한도, 견적 TTL 값은 "소스 확인 후"로 남겼다.

## 결정
1. **소스**: 1차 Upbit 공개 REST(시세 그룹 IP 당 초당 10건 확인), 2차 CoinGecko(Demo 월 1만 호출). **KRW-USDC 상장 여부와 CoinGecko 의 KRW 지원·분당 한도는 미확인**이므로 Phase 5 착수 시 확인한다. 직접 시세가 없으면 KRW-USDT 프록시를 쓰되 스냅샷 `source_note` 와 UI 면책에 기록한다.
2. **주기**: 1차 5분, 2차 10분(CoinGecko 5분은 월 8,640회로 Demo 한도의 87%라 여유가 적다).
3. **채택 규칙**: 양수·범위(800~2,500 KRW/USDC, 설정)·직전 대비 ±3%·소스 간 1% 이내·소스 시각 신선도. 하나라도 어긋나면 **보류(`held`)** + 경보. 이전 스냅샷을 새것처럼 쓰지 않는다.
4. **허용 지연 15분**(= 수집 주기×3), 초과 시 **견적 발급 거절(fail-closed)**, 이미 만든 견적·결제는 영향 없음.
5. **견적 TTL 5분**, 결제 시작에서 **1회만** 사용(`open→used` 조건부), 사용 시 스냅샷 id 를 결제에 **고정**. 승인이 견적 만료 후에 와도 결제 TTL 안이면 고정된 스냅샷을 쓴다.
   **포인트 결제도 결제 시작 시 최신 accepted 스냅샷을 서버가 고정**한다(견적 UI 는 카드 전용). 정산이 모든 결제에서 환율 근거를 갖게 하기 위함이며(포인트 결제 주문의 정산 영구 실패 결함 해소), 그 결과 시세 장애는 포인트 구매 시작에도 영향을 준다(`pricefeed_stale` 로 거절, 의도된 fail-closed).
6. 수치는 모두 제안이며 소스 확인 후 조정한다.

## 설계 상세
수집 시퀀스·검증 표·견적 상태 머신·정산과의 연결은 설계 문서 §8.

## 대안과 기각 이유
- **단일 소스**: 소스 오류가 곧바로 결제 환율이 된다.
- **오래된 시세 계속 사용(fail-open)**: 잘못된 가격 결제(ADR-011 에서 기각).
- **결제 시점마다 실시간 조회**: 호출 한도·지연·장애 전파.

## 결과
- 얻는 것: 감사 가능한 환율, 장애 시 안전한 실패, 이상값 방어.
- 치르는 것: 수집·검증 작업, 시세 장애 시 신규 결제 불가(의도).

## 위험과 완화
| 위험 | 완화 |
|---|---|
| 소스가 KRW-USDC 를 안 줌 | 프록시+기록, 교차 검증 |
| 소스 약관이 재배포/상업 이용을 제한 | 포트폴리오 모의 용도 확인, 표시 출처 명시 |
| 괴리 한도가 너무 빡빡해 보류 남발 | 지표(`pf_pricefeed_held_total`)로 조정 |

## 검증 방법
AC-C13~C16, 시세 장애·이상값 주입(`FakePriceSource`), 환산 속성 시험.

## 실서비스라면
이중화된 유료 시세 소스와 거래소 약관 준수, 시세 지연 SLA.

## 재검토 조건
Phase 5 착수 시 소스 확인 후. 소스 한도에 닿을 때.

## 관련 ADR
ADR-011, ADR-015, ADR-016, ADR-040
