# ADR-003: 완전 무료 호스팅 — 집 PC 와 Oracle 양쪽 지원, 정적 폴백
- 상태: Accepted
- 날짜: 2026-11-03
- 근거: 명세 FR-070, AC-010·014, 가정 A-006~A-009 / 인터뷰 R3-Q3, R5-Q1, R7-Q1 / 호스팅 조사(2026-11-03, 공식 문서 기준)

## 맥락
개인 도메인을 쓰고 **완전 무료(0원, 카드 청구 위험 최소)** 로 상시 공개하길 원한다. 백엔드는 Docker 컨테이너(Postgres, 이벤트 처리, WebSocket, 지표)로 구성된다. 또한 방문자의 첫 인상이 곧 평가이므로 **서버가 꺼진 순간에도 핵심 정보는 보여야** 한다.

## 결정
- 같은 Compose 한 벌을 **집 PC(+Cloudflare Tunnel)** 와 **Oracle Always Free(Arm)** 양쪽에서 띄울 수 있게 설계한다. **1차 가동은 집 PC.**
- 도메인 DNS 는 Cloudflare 무료 DNS 에 둔다(가정 A-006).
- 백엔드가 죽으면 자기소개·아키텍처는 **정적 폴백**으로 계속 제공하고 데모 영역만 '점검 중'을 보인다(FR-070).

## 설계 상세

### 정적 폴백(구현 방식은 미확정, 가정 A-008)
후보: Next.js 가 정적으로 내보낸 자기소개·아키텍처 페이지를 Cloudflare 무료 정적 호스팅에 올려 두고, 원본 서버 오류 시 그쪽을 응답하게 한다. 구체 방식(라우팅 규칙 vs 오류 페이지 대체)은 구현 시 시험으로 정한다. **데모 영역은 폴백 대상이 아니다.**

### 이중 지원의 원칙
호스트별 차이는 오버라이드 파일로만 둔다(ADR-002). 터널(`cloudflared`)은 집 PC 쪽 오버라이드에만 존재한다.

## 대안과 기각 이유
표의 '기각' 행 참조. 요지: 무료 24시간 가동이 안 되거나, 카드·도메인 제약이 있거나, Docker·Postgres 설계를 버려야 한다.

## 결과
- 얻는 것: 0원, 카드 불필요(집 PC 경로), 이전 가능성.
- 치르는 것: 집 PC 가동률이 곧 사이트 가동률. Oracle 은 카드가 필요하고 회수·재고 부족 위험이 있다.

## 위험과 완화
| 위험 | 완화 |
|---|---|
| 🔴 **터널이 WebSocket 을 통과시키는지 공식 확인 못함** | 구현 초기에 실측. 안 되면 SSE 등으로 대체하는 후속 ADR |
| 집 정전·회선 장애 | 정적 폴백(FR-070), 필요 시 Oracle 로 이전 |
| Oracle 유휴 회수 | 정기 부하를 만들거나 이용을 포기하고 집 PC 유지 |
| 무료 정책 변경 | 이중 지원 구조 자체가 완화책 |

## 검증 방법
AC-010(백엔드 중단 시 폴백), AC-014(양쪽 호스팅에서 핵심 시나리오), 터널 WebSocket 실측.

## 실서비스라면
항상 켜진 관리형 호스트와 헬스체크 기반 장애 조치를 쓴다.

## 재검토 조건
터널 WS 실측 실패, 집 회선 가동률 불만족, 무료 정책 변경.

## 관련 ADR
ADR-002, ADR-014
